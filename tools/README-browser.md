# Проверка браузером

Полный путь автора настоящим Chromium: нажатия, перетаскивания, экраны.

До неё всё проверялось запросами или jsdom. Обе проверки не раз проходили на
сломанном приложении: jsdom не раскладывает страницу, поэтому он, например, ни
слова не сказал о том, что связь между точками не рисуется вовсе.

## Как запустить

Бинарник Chromium лежит внутри npm-пакета `@sparticuz/chromium`, поэтому
качать ничего не нужно — только распаковать:

```
node -e "const f=require('fs'),z=require('zlib');
f.writeFileSync('/tmp/chromium', z.brotliDecompressSync(
  f.readFileSync('node_modules/@sparticuz/chromium/bin/chromium.br')));
f.chmodSync('/tmp/chromium', 0o755)"
```

Дальше поднимаются оба сервера и запускается прогон:

```
# в wob-back:  WOB_DEV_LOGIN=true в .env
php artisan serve --host=127.0.0.1 --port=8000

# в wob:  VITE_DEV_LOGIN=1 в .env.local
npx vite --port 5173

node tools/browser-flow.mjs
```

## Про адрес

Открывать надо `http://localhost:5173`, а не `127.0.0.1:5173`. Это не
придирка: `SANCTUM_STATEFUL_DOMAINS` перечисляет `localhost`, и с другого
написания того же адреса сессия не считается своей — все запросы отвечают 401.
На это я потратил первый прогон.

## Что прогон делает

Вход как разработчик, создание истории, глава, уровень кнопкой «+», возврат из
редактора уровня, перетаскивание плитки уровня в главу указателем, выпуск
релиза. По дороге собирает ошибки консоли, необработанные исключения и все
ответы 400+; снимки экрана кладёт в `/tmp/shot-*.png`.
